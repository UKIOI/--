# 战术扩展：建筑、虫群、事件与操作

## 操作

- 点击防御塔后，点击“操控此塔”或按 E。鼠标指向射程内敌人，按住左键持续攻击；E、Esc 或右键退出并恢复自动索敌。一次只操控一座，其他塔继续自动工作。保留原射程、对空/对地、冷却及直射遮挡限制；不对空白位置开火。支持箭塔、迫击炮、加农炮、狙击塔、防空塔和冰霜塔。
- Shift + 点击增选或取消建筑。侧栏显示可升级数量、各建筑两个分支名称及总费用，统一升级方向 1 或 2。已升级、下落或被毁建筑跳过，费用在执行时重新计算；金币不足整组取消，重复选择不会重复扣费。升级保留当前生命比例。
- 手控和选择是临时操作状态，读档恢复自动模式且保持暂停；事件预警、空降进度、护盾和弹道会保存。

## 建筑表现

全部 11 种建筑保留各自主体，升级新增结构部件：墙体加固梁/尖刺、重弩加强弓臂/连弩供弹轮、重炮套筒/速射副炮管、狙击加长枪管/测距镜、防空重装/广域设备、矿场井架/底座、维修机械臂/天线、冰晶/冰环、增幅电容/波束环、桥梁加固/反伤尖刺。

生命低于 70% 显示裂纹，低于 35% 增加结构缺口、火星和烟雾。使用升级与强化后的最大生命计算，维修后恢复外观。“减少动态效果”关闭烟雾动画及通告入场位移，保留危险标记。

## 突发事件与 Boss

首次事件在 2:30 后触发，之后至少间隔 110 秒；导弹齐射与空降交替。Boss 登场前 20 秒、预警期间及存活期间不启动新事件，避免两类攻势叠加。旧存档加入事件时至少保留 20 秒准备期。

- **导弹齐射**：6 秒倒计时，标记三列，优先选择高投入建筑所在列。从战区右上方发射三枚实体导弹，途中碰撞建筑后爆炸；基础 65 伤害、半径 1.3，随威胁小幅增长。导弹本身不可被塔拦截。
- **空降入侵**：6 秒预警后，三只带降落伞的普通怪在 11、17、23 列降落；可在空中被防空塔击杀。成功投放数量从后续普通刷怪额度扣除，遵循怪物数量上限。
- **Boss 范围攻击**：碎墙巨兽近战半径 1.6，冲撞撞击半径 2，可伤害邻近与上层建筑；已有踏地震波、巨岩、母舰导弹和激光保留范围伤害与蓄力提示。
- Boss 倒计时、登场和突发事件使用紧急通告横幅、警戒色、地面标记及双段警报音。通告不拦截鼠标，不强制暂停。

## 验证与限制

新增引擎测试覆盖减伤、反射、破盾、散阵、跳跃、酸液、Boss 范围伤害、事件恢复、空降目标切换、手控冷却、批量升级原子性。接口测试覆盖新增存档字段和事件区域校验。Chromium / Firefox 使用隔离 API 数据验证图鉴、分支外观、多选升级、手控与事件提示，不覆盖玩家存档。

数值集中在 `content/game-config.json`。这些是首版试玩数值，自动化正确性与稳定性检查不代表人工平衡验收完成。

本次验证：前端构建通过；47 项前端测试（分组运行）及 9 项接口测试通过；8 项 Chromium / Firefox 相关浏览器场景通过。包含 216,000 步、一小时无渲染人工压力模拟，结果见 `stability-result.json`。该夹具每帧将核心补至十亿生命并持续补充敌军，以保证压力负载，不代表正常游戏生存结果；运行耗时约 204 秒，因此将该长期测试时限扩展到 300 秒。两种自动建造策略的结果另见 `balance-result.json`，不能替代人工平衡试玩。
