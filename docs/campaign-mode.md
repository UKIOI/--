# 故事战役：黎明计划

主菜单选择「故事战役 · 黎明计划」。各关独立建设；完成当前关后永久解锁下一关，已通关地图可重玩。进行中战局、通关状态和解锁进度支持本地服务及离线分享版保存。进入战役会沿用已有的新局覆盖确认和备份流程。

背景故事由一座幸存核心开始，经过城市供能、沙海通道、北方雷达，最终在海港击破入侵通道。每关提供剧情简报、作战提示、新设施和专属目标；战役固定地图与难度，设置中可以调整音量、布局等。

解锁按关卡累积。未解锁建筑无法通过点击或快捷键建造，未解锁敌人不会进入本关刷怪池；Boss 召唤也遵守该名单。事件随章节引入，首关不出现突发事件。战役与无尽生存、双线测试相互独立，不能同时开启双线测试。

击败该关所有统领后通关。母舰仍保留坠落残骸机制，必须在残骸落地前守住核心；核心先被摧毁仍判失败。胜利后停止计时、刷怪和伤害，不再弹出强化选择。终章采用独立的黎明胜利画面，展示五地恢复、三统领击破及结局叙事。

验证覆盖全部地图与解锁名单、锁定建筑/敌人、各关定时 Boss、双 Boss 同场、击杀一个不胜利、残骸后的胜利、胜利存档恢复、解锁持久化、关卡推进，以及 Chrome / Firefox 的地图、简报和结算交互。数值为初版战役配置，后续可依据实际游玩反馈调整。

## 0.2.0 港湾终章

8:00—10:00 普通刷怪频率降至 35%，暂停新增突袭事件，已有敌人与已发出的攻击照常推进。减压期间 HUD 显示整备倒计时。

深渊潮汐领主仅在新版终章出现，基础生命 3600、物理护甲 18%，随既有难度和时间机制成长。三重潮汐在 3.5 秒起步的预警后造成 2.6 格范围伤害；深水雷从本体发射，半径 1.6，可被拦截阵列击落。半血时两种技能冷却由 15/19 秒缩短为 10/13 秒，同时生命伤害增加 15%。

新战役存档标记 timelineVersion=2。旧版终章存档沿用独立保存的旧关卡定义与双 Boss 胜利条件；重玩终章才使用新版。若女王仍存活，10:00 允许三 Boss 同场。胜利必须满足三名统领均击败且母舰残骸落地。

## 0.3.0 沉船苏醒

新存档 timelineVersion=3，4:00 女王、8:00—10:00 整备、10:00 仅母舰。carrierCrashed 在母舰残骸碰撞伤害结算且核心存活后置位，随后 revealFrame 从 0 推进到 720（12 秒）；期间世界 tick、战斗与经济冻结。第 180/500 帧播放船体声，240 帧播放波涛；720 帧生成中央巨型领主并启用 storm。玩家命令与界面操作被阻断，失焦暂停，读档续播，不跳过最终 Boss。falseEndingAchievement 随设置单调持久化。

领主位于 (12,7)，命中区域为 8×14 格，前景艺术宽 11.5、高 14 格；不受建筑碰撞挤出中央，仍可被防御塔命中。雨幕与低频闪电按模拟时间绘制；减少动态效果时使用静态雨线且不闪屏。v1/v2 终章通过各自历史关卡定义续玩，不强制迁移旧进度。
