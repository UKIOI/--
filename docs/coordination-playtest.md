# 空中堡垒与虫群协同

- 空中堡垒为普通重型空中单位，420 秒后加入刷怪池，基础生命 1800、护甲 20%，随难度、时间和精英规则成长，场上最多 2 艘。
- 进入战区（横坐标 ≤27）4 秒后首次从舱门空投：步兵、酸液虫、护甲虫、步兵。之后每 18 秒一批，遵守敌人数量上限，降落过程中属于空中目标。
- 击毁后残骸预警 3 秒，再用 3 秒落地，途中撞到建筑会提前爆炸。4 格范围、基础 320 伤害，随攻击倍率成长。爆炸伤害建筑及地面怪物，不伤空中怪物；潜地沙虫仍不可攻击。坠爆没有额外 Boss 奖励。
- 指挥虫影响半径 14 格。地面部队向附近仍有护盾的护甲虫靠拢；护甲虫等待后方部队。2.6 格范围内，护盾承担 70% 来袭伤害并真实消耗，护盾耗尽或指挥虫死亡就失效。堡垒误伤不通过这层共享护盾转移，自身护盾仍生效。
- 指挥中的堡垒优先吸引射程内自动防空火力；不会让射程外的塔锁定它。手动瞄准与母舰部位指定保留优先权。
- 受指挥的自爆飞船进入战区后在堡垒后方集结；没有堡垒时在后方空域集结。达到 3 艘或最早一艘等待 10 秒后齐袭同一高价值目标。指挥虫死亡或离开指挥范围会提前出击。集结数量、倒计时及指挥连线可见，状态可保存。

验证包含真实护盾消耗、队伍靠拢、堡垒数量与空投实体、集群齐袭、超时与指挥中断、存档恢复一致性、坠爆误伤及自动/手动防空目标；浏览器检查新增外观与图鉴。
