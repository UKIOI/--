# 新建筑扩展

此次用户需求优先于 PRD V1 原先“不做横梁”的范围限制。原八种建筑数值保持不变，旧存档兼容。

| 建筑 | 费用 | 生命 | 基础能力 | 升级费用 / 分支 |
| --- | ---: | ---: | --- | --- |
| 桥梁 | 45 | 350 | 一格一段，可横向连接支撑并承载上层 | 70：钢桁桥 800 生命 / 堡垒桥 550 生命、近战反伤 20 |
| 加农炮 | 150 | 260 | 对地直射，90 爆炸伤害，半径 1.5，射程 10，间隔 2.2 秒 | 170：155 伤害、半径 2 / 间隔 1.2 秒 |
| 狙击塔 | 180 | 160 | 对地直射，200 物理伤害，射程 24，间隔 3.5 秒 | 200：350 伤害、间隔 4.2 秒 / 射程 32、间隔 2.6 秒 |

桥梁使用快捷键 9，加农炮 0，狙击塔 -，也可以点击建筑栏。桥梁点击目标格的高度直接铺设，其余建筑仍从顶部下落。每次只建一段桥，共用投放冷却。

支撑从地面和核心传播：任何建筑可竖直承载；只有桥段能从同高度相邻、已经具有可靠支撑的建筑获取侧向支撑。桥段可以继续横向传递支撑，不限制跨度。闭合但悬空的桥群无法自支撑。桥梁可以形成双端支撑，失去一端时另一端仍可承载。

所有支撑路径断开后，桥段与所承载建筑受重力坠落，不伤友方；坠落期间停止工作，落到下方实体后恢复。地面敌人仍沿地面走，桥下空隙不会阻止通行。

加农炮开火前检查直线遮挡；炮弹从炮口以每秒 18 格飞行，锁定开火时目标位置，在碰撞或到达终点时爆炸，不跟踪、不伤友军，并忽略敌人护甲。箭塔改为每秒 22 格的实体箭矢，碰撞首个敌人后造成物理伤害，途中建筑可挡住箭矢。两种实体弹道都支持飞行中保存和恢复。狙击塔为即时物理命中，受护甲减免与直线遮挡影响。武器均受增幅器与火力强化影响。

桥梁采用空心钢桁架、连续桥面、端板与铆钉，升级后增加加固构件或反伤尖刺。桥梁的支撑规则保持一致。

初始数值集中于 content/game-config.json，仍需后续实际试玩平衡。
