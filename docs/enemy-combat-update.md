# 怪物动作与 Boss 攻击扩展

## 动作与反馈

怪物新增呼吸起伏、步伐、履带轮转动、旋翼变化、母舰引擎喷流。攻击瞬间有前扑动作；普通怪与疾跑怪使用爪痕，攻城怪使用撞击环，飞行怪使用能量攻击线。巨兽冲撞保留方向预警并增加冲刺尾迹。

动画读取模拟时间，暂停、失焦或强化选择期间冻结。减少动态效果保留技能名称、范围、倒计时及炸弹本体，关闭装饰性摆动、烟迹与震动。

## 实体炸弹

轰炸怪与母舰先给出锁定预警，预警结束时从机体当前坐标释放炸弹。实体拥有独立编号、释放坐标、飞行阶段、持续时间、剩余时间、锁定位置及伤害；默认飞行 0.9 秒，有加速下落和尾迹。导弹使用单独的弹体与尾焰，巨岩使用抛物线轨迹。

碰撞按每个固定步的完整移动线段扫掠计算，命中途中第一个友方建筑或核心后爆炸，包含下落建筑。无障碍时到锁定落点爆炸。实体炸弹目前不能被防空火力拦截。

Boss 死亡取消未执行的预警，但已经释放的炸弹、导弹与巨岩继续飞行。新增技能冷却和射弹阶段进入快照，读档不会重置飞行位置。旧存档中没有阶段的投弹按待执行预警处理。

新增自动化验证覆盖释放坐标、屋顶扫掠碰撞、单次伤害、Boss 死亡取消预警、两类 Boss 新招、攻击姿态、暂停和确定性保存恢复；浏览器测试使用接口拦截，不修改玩家存档。
