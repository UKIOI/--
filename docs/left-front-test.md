# 十分钟双线测试模式

主菜单勾选「测试模式：10 分钟后开启左侧战场」，再建立新防线。该选项仅决定新局；普通战局和旧存档默认不启用。建立新局仍走已有的存档覆盖确认与备份流程。

- 9:30 预警，10:00 开启左侧战场，10:20 首批左翼敌人进入。
- 新增核心左侧 20 列建造区（L20—L1），入口在更左方。点击「左侧战场 / 右侧战场」切换视角，保持原有格子显示比例。
- 切换只改变视角，两边持续模拟，共用金币、核心生命、强化、建筑上限、编队和投放冷却。切换时停止手动开火及投放预览，避免误操作。
- 左翼试验兵种为步兵、猎手、攻城重甲、酸液虫、飞行虫，从左向右进攻。伤害、生命沿用难度和时间成长，增援间隔逐渐缩短，和右翼共用敌人数上限。
- 左侧支持建造、桥梁支撑、拆除坍塌、升级、吊装、自动与手动攻击。左翼地面敌人攻击前方障碍，飞行敌人攻击同一个核心。
- 本阶段 Boss 与特殊事件仍主要在右翼出现。两线敌人数显示在切换按钮中，应经常检查另一条防线。
- 模式、开放状态、刷怪时间、负坐标建筑与左翼单位随存档保存。暂停冻结计时，读档不会重新计算一次 10 分钟开放时间。

测试覆盖 599.983→600 秒边界、20 秒部署时间、标准模式无变化、负坐标落稳、向右近战与酸液、防空、暂停、恢复确定性、服务端合法性，以及双浏览器中的视角切换、点击建造和读档。
