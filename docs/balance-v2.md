# 平衡调整第 2 版

本轮目标：抑制范围武器同时占据单体与群体优势，区分升级用途，改善低成本开局与后排生存，保留三档难度差异。以下单次“伤害/治疗”中，维修站为治疗量，矿场等非武器为零。

主要变化：加农炮爆炸半径 1.5→1.1，重型分支 2→1.5；迫击炮半径 1.3→1.2，重炮分支 1.8→1.75。矿场回本约 85 秒，深井升级额外产量回本约 100 秒；加固矿以较慢回本换取更高耐久。增幅器适合密集阵地，维修站优先维持前墙，不能抵消整支怪群的输出。

每分钟敌人生命增长 14%→12%，伤害增长 10%→7%；出兵速率增长 0.045→0.05，形成更持续的怪群压力。碎墙巨兽冲撞基础伤害 300→225；母舰导弹 130→90，齐射间隔 12→16 秒，三列轰炸 145→95、间隔 7→10 秒，召唤间隔 12→18 秒。母舰的召唤、导弹、轰炸和激光均保留。护甲虫基础盾量 120→95，隔爆甲兽爆炸减伤 55%→50%。

## 对比方法与结果

对更新前后各运行三个种子、三档难度、三种固定合法建造策略，共 54 局，最长模拟 12 分钟。使用正常收入、冷却、建筑下落和强化选择；没有额外补钱、补血或瞬间建造。所有策略共用经济、防空、前墙及低生命城墙升级策略，主要地面火力分别偏混合、加农或狙击。结果见 `balance-v2-study.json`。

| 模式 / 策略 | 更新前平均生存秒数 | 更新后平均生存秒数 |
| --- | ---: | ---: |
| 简单 / 混合 | 387 | 412 |
| 简单 / 加农 | 396 | 422 |
| 简单 / 狙击 | 416 | 477 |
| 普通 / 混合 | 252 | 395 |
| 普通 / 加农 | 142 | 154 |
| 普通 / 狙击 | 142 | 154 |
| 困难 / 三种策略 | 91 | 94 |

混合阵型在普通模式下表现改善，加农没有全面领先。简单模式狙击仍有射程优势。困难模式中这些经济开局策略均在阵型成形前失败，不能据此评价困难模式的后期平衡。样本较少且没有手控、主动拆迁、针对性集火，结果是调参依据，不代表所有打法都已平衡。

## 旧存档与验证

平衡修订号为 2，存档结构版本仍为 1。首次读取旧局按新旧基础/分支生命比率适配建筑与怪物，保留受损比例；护盾、护甲和奖励也适配。实际投入、金币、位置、升级方向不变，返还金额继续按实际投入计算。已经发射的弹体保留原伤害，存活敌人的既有等级成长倍率保留，新生成怪物采用新成长曲线。修订号防止重复换算。前端浏览器副本和后端读写都支持适配，不直接改写原数据库文件。

机制回归使用固定旧数值夹具，以免伤害常量变化掩盖机制问题；新平衡数据另有升级收益、武器分工、三档确定性恢复和跨版本存档测试。浏览器使用隔离 API 验证实际新数值和旧存档界面。

本次构建、71 项前端测试（包括 54 局对比模拟）、11 项接口测试，以及 6 项 Chromium / Firefox 浏览器场景通过。本轮未重新执行历史的一小时人工补血压力测试；旧的 `stability-result.json` 不代表本轮数值的平衡结论。

核心生命、初始金币、三档难度倍率与穿透规则保持不变。普通怪群更持续，后期伤害增长放缓；武器与升级分支按职责区分。
