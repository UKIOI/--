# 难度、穿透与母舰更新

首页选择新局难度；游戏内“设置 → 当前战局难度”可以调整已有战局。旧存档默认简单。切换会保留敌人当前生命比例并调整生命、护盾和攻击，之后按新速率出兵；已发射弹体保留原伤害。模式随存档保存，HUD 显示当前模式。

| 模式 | 敌人生命 | 敌人伤害 | 出兵速率 |
| --- | ---: | ---: | ---: |
| 简单 | ×1 | ×1 | ×1 |
| 普通 | ×1.45 | ×1.25 | ×1.35 |
| 困难 | ×2.1 | ×1.6 | ×1.7 |

三档共享怪物数量上限；在原有等级成长上叠加倍率。简单是原数值基线，母舰强化在所有模式生效。

**穿透规则**：简单、普通中，玩家子弹、箭矢、炮弹穿过全部友方建筑。困难中，狙击子弹仍能穿过城墙，箭矢、炮弹碰到城墙会被阻挡，但能穿过其他建筑。迫击炮可以沿抛物线越墙，不能直接穿过墙体。只穿友方结构，不穿透敌人；敌方弹体和护甲虫返弹仍会撞击友方建筑。难度选择与设置页明确显示规则。

狙击塔改为 48 格/秒的实体子弹，带明亮弹头与曳光；命中时结算物理伤害，飞行中可保存恢复。保持射程、伤害、冷却和护甲规则。

异形母舰在 X≤30 时开始攻击准备，无需等到 X=18 的悬停点。首次召唤倒计时 3 秒，之后每 12 秒召唤三只飞行护航怪和一只空降酸液虫，遵守敌人上限。四枚导弹的基础伤害为 130、爆炸半径 1.7；三列地毯轰炸基础伤害 145，每 7 秒发动，保留释放前预警。激光攻击保留。母舰外观新增装甲翼、弹仓、发光机库与尾焰。

播报修正：操作错误提示在 3 秒模拟时间后清除；新怪物提示准确说明“加入刷怪池”，按解锁时间排序；Boss 和事件通告显示时不再叠加重复顶部提示。怪物图像追加甲壳纹理、膜翼骨架、口器、眼部和机械细节，图鉴与战场使用同一套绘制。

验证：穿透矩阵、不同难度成长、实体狙击弹恢复、母舰召唤与轰炸、错误提示到期等测试；接口保存难度与子弹字段；Chromium / Firefox 检查难度切换、规则告知和图鉴。自动化验证不代替人工平衡试玩。
