# 部队、指挥学院与宽阔布局

Shift 点击建筑多选。选择「编入目标部队」后点加入，可追加当前选择；替换编队会用当前选择覆盖，清空仅移除编队记录，不拆除建筑。

- F1—F5：选择并接管对应部队。
- Ctrl + F1—F5：将当前选择追加到对应部队。
- Ctrl + Shift + F1—F5：用当前选择替换对应部队。
- 双击防御塔选中全部同类型塔（包含不同升级分支），已落稳成员一起接管；单击直接接管一座。Shift 点击只多选，不接管。
- 按住左键向光标位置持续射击；点击另一座建筑切换选择，右键退出操控。未接管的塔自动战斗。

编队随战局保存，同一建筑可属于多个队，死亡成员自动忽略；生产建筑可以编队与批量升级，但不能手动开火。已落稳的武器塔共同瞄准，各自遵守射程、对空或对地、最小射程、遮挡与冷却。旧存档默认为空编队。

指挥学院重做为 13 章：目标、建造支撑、手控、升级回收、编队、全部建筑与分支、经济与全部强化、难度射界、全部怪物与协同、Boss 部位、全部事件补给、保存设置、出发检查。四项实操使用独立 Engine；练习、跳过、完成均不修改战局。首次运行自动显示，也可从设置重新体验。章节目录可随时跳转。

默认宽阔布局压缩顶部、边距和建筑栏，保留侧栏及完整 36×16 战场。设置中可即时切换经典布局，选择会持久保存；不改变射程、建造坐标或存档位置。1280×720 双浏览器测试确认单位显示尺寸比经典布局大至少 15%。

验证包括编队追加去重、存档恢复、整队开火与退出、成员死亡、鼠标直控、快捷键、目标槽位点击、布局切换保存、学院四项练习与跳过，以及不写入正式战局。
